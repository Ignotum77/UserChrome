# UserChrome
`userChrome.css` and `userContent.css` for FireFox, Thunderbird and Betterbird

These are my personal improvements.

## How to install
1. `about:config`
2. set `toolkit.legacyUserProfileCustomizations.stylesheets` to true  
   if you want my `userContent.css` for Firefox, add the following to `about:config`:  
    `userChrome+Content.newtab.image.BibleStudy`  
    `userChrome+Content.newtab.image.BibleStudy1`  
    `userChrome+Content.newtab.image.BibleStudy2`  
    `userChrome+Content.newtab.image.AlleenZijn`  
    `userChrome+Content.newtab.image.Begrepen`  
    `userChrome+Content.newtab.image.Bidden`  
    `userChrome+Content.newtab.image.ZichzelfZijn`  
   and set one of them on true  
   (last four images are Dutch quotes)
4. download the css files
5. head over the your user profile folder of Firefox of Thunderbird or Betterbird
6. make a folder called `chrome`
7. put the downloaded files there
