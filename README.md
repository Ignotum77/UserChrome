# UserChrome
`userChrome.css` and `userContent.css` for FireFox, Thunderbird and Betterbird

These are my personal improvements.

## How to install
1. `about:config`
2. set `toolkit.legacyUserProfileCustomizations.stylesheets` to true
3. download the css files
4. head over the your user profile folder of Firefox of Thunderbird or Betterbird
5. make a folder called `chrome`
6. put the downloaded files there
